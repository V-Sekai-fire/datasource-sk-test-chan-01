# datasource-sk-test-chan-01

A game-engine project that prepares the public-domain Test-Chan avatar for upload to a social VR platform.

## What it is for

It holds the avatar's source files, the toon shader its materials use, and the converted avatar scene. The preparation adds face shapes, removes transparent triangles, keeps the blend shapes on the body mesh, and replaces sphere colliders with capsules until the platform's performance rank is acceptable.

## Run

Open the project in the editor version its project settings pin, then open the avatar scene.
